# Finding addendum — operation structure is tractable, semantic correctness remains open

The full public question set can be transformed into a typed computation shape
without asking a generative model to improvise a Pandas expression.  This
supports the architecture decision to place a deterministic planner between
retrieval/grounding and compilation.  The strongest guard discovered so far is
that financial metric names containing `tổng` are ordinary lookups unless an
explicit additive cue appears.  The next evidence needed is annotation, not a
larger unlabelled benchmark.
