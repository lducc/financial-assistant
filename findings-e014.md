# Finding addendum — rule disagreement is a better annotation target than random volume

The two rule systems disagree chiefly where ordinary financial wording is easy
to confuse with arithmetic intent: a metric name containing “tổng”, or a
comparison that might request a difference or a rate of change.  These are
high-information examples for annotation and cue refinement.  Agreement alone
must not be mistaken for correctness because both systems are lexical.
